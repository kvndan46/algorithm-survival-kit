# Массивы

## 1. Определение массива

**Массив (Array)** — это структура данных, представляющая собой **упорядоченную коллекцию элементов**, где:
- Все элементы имеют **одинаковый тип данных** (в статически типизированных языках)
- Каждый элемент доступен по **индексу** — целому числу, определяющему его позицию
- Элементы хранятся в **непрерывной области памяти** (последовательно друг за другом)

```python
# Python список (динамический массив)
numbers = [10, 20, 30, 40, 50]
# В памяти: [10][20][30][40][50]
# Индексы:   0   1   2   3   4

print(numbers[0])  # 10
print(numbers[2])  # 30
```

## 2. Свойства массива

### 2.1. Непрерывность памяти (Contiguous Memory Allocation)

Главная отличительная черта массива. Все элементы располагаются в памяти **последовательно**, без разрывов.


**Как следствие:** *Зная адрес первого элемента и размер одного элемента, можно вычислить адрес любого элемента по формуле* :

```
address_of_element[i] = base_address + i * element_size
```

### В языках может быть как фиксированный размер, динамический размер массива

В классическом определении (статический массив) размер задается при создании и **не может быть изменен**.

```c
// C — статический массив (размер фиксирован)
int arr[10];  // размер = 10, изменить нельзя
```

**Python:** все списки — динамические массивы (автоматически расширяются)

```python
# Python — динамический массив (размер меняется)
arr = []           # пустой список
arr.append(1)      # размер = 1
arr.append(2)      # размер = 2
arr.append(3)      # размер = 3
print(len(arr))    # 3
```

### 2.2. Однородность (Homogeneity)

Все элементы массива имеют **один и тот же тип данных**. Это позволяет компилятору точно знать, сколько байт занимает каждый элемент.

```python
# В Python списки могут быть гетерогенными (смешанные типы)
mixed = [1, "hello", 3.14, True]  # Это возможно, но неэффективно

# Для однородных данных лучше использовать array или numpy
from array import array
int_array = array('i', [1, 2, 3, 4, 5])  # только целые числа
```

## 2.3. Алгоритмические сложности над массивом

| Операция | Сложность | Объяснение |
|----------|-----------|------------|
| **Доступ по индексу** | O(1) | Прямое вычисление адреса, не зависит от размера |
| **Поиск по значению** | O(n) | В худшем случае нужно проверить все элементы |
| **Вставка в конец** | O(1)* | Если есть свободное место; *при переполнении — O(n) |
| **Вставка в начало/середину** | O(n) | Нужно сдвинуть все последующие элементы |
| **Удаление с конца** | O(1) | Просто уменьшить счетчик |
| **Удаление из начала/середины** | O(n) | Нужно сдвинуть все последующие элементы |

```python

import time

# Доступ по индексу — O(1)
arr = list(range(1000000))
start = time.time()
x = arr[500000]  # Мгновенно, независимо от размера
print(f"Доступ по индексу: {time.time() - start:.6f} сек")

# Вставка в начало — O(n)
arr = list(range(100000))
start = time.time()
arr.insert(0, -1)  # Сдвигает все 100000 элементов
print(f"Вставка в начало: {time.time() - start:.6f} сек")

# Вставка в конец — O(1) амортизированно
arr = list(range(100000))
start = time.time()
arr.append(100000)  # Быстро, сдвигать ничего не нужно
print(f"Вставка в конец: {time.time() - start:.6f} сек")
```

### 2.3. Одномерные и многомерные

**Одномерный массив** — линейная последовательность.

```python
# Одномерный массив
one_d = [1, 2, 3, 4, 5]
```

**Двумерный массив** — "массив массивов".

```python
# Двумерный массив (матрица 3x3)
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

print(matrix[0][1])  # 2 — первая строка, второй столбец
print(matrix[2][2])  # 9 — третья строка, третий столбец

# Обход по строкам (row-major)
for row in matrix:
    for element in row:
        print(element, end=" ")
# Вывод: 1 2 3 4 5 6 7 8 9
```
## 3. Массив в памяти: низкоуровневый взгляд

### 3.1. Cache Locality (Кэш-локальность)

Непрерывное хранение элементов делает массивы **чрезвычайно кэш-дружественными**. При обходе массива процессор загружает в кэш блоки памяти, содержащие несколько элементов.

```python
import time
import random

# Создаем большой массив
size = 10_000_000
arr = list(range(size))

# последовательный доступ (хорошая локальность)
start = time.time()
total = 0
for x in arr:
    total += x
print(f"Последовательный доступ: {time.time() - start:.3f} сек")

# случайный доступ (плохая локальность)
indices = list(range(size))
random.shuffle(indices)

start = time.time()
total = 0
for i in indices:
    total += arr[i]
print(f"Случайный доступ: {time.time() - start:.3f} сек")
```

### 3.2. Амортизированный анализ

Динамические массивы используют следующую стратегию:
1. Начинают с начальной емкости (например, 10)
2. При добавлении элемента в конец, если массив заполнен:
   - Создают новый массив в 1.5–2 раза больше
   - Копируют все элементы
   - Освобождают старый массив

**Амортизированная сложность** вставки в конец — O(1), потому что дорогое копирование происходит редко.

```python
# Визуализация амортизированного анализа
import sys

arr = []
total_cost = 0
operations = 20

print("Операция | Размер | Емкость | Стоимость | Общая стоимость")
print("-" * 60)

for i in range(operations):
    old_capacity = sys.getsizeof(arr)
    arr.append(i)
    new_capacity = sys.getsizeof(arr)

    if new_capacity > old_capacity:
        # Копирование всех элементов (стоимость = текущий размер)
        cost = len(arr) - 1  # количество скопированных элементов
    else:
        cost = 1  # просто добавление

    total_cost += cost
    print(f"{i+1:8} | {len(arr):6} | {new_capacity:7} | {cost:9} | {total_cost:16}")
```

## 4. Массив в разных языках программирования

| Язык | Статический | Динамический | Особенности |
|------|-------------|--------------|-------------|
| **C** | `int arr[10];` | `malloc()` + ручное управление | Нет проверки границ |
| **C++** | `int arr[10];` | `std::vector<T>` | RAII, итераторы |
| **Java** | `int[] arr = new int[10];` | `ArrayList<T>` | Проверка границ, объекты |
| **Python** | — (все списки динамические) | `list` | Гетерогенный, автоматическое управление |
| **JavaScript** | — | `Array` | Гетерогенный, разреженные массивы |

```python
# Python примеры различных типов массивов

# 1. Обычный список (динамический, гетерогенный)
py_list = [1, "hello", 3.14]
py_list.append(True)

# 2. Массив из модуля array (гомогенный, эффективный)
from array import array
int_array = array('i', [1, 2, 3, 4, 5])
# int_array.append("text")  # Ошибка! Только целые числа

# 3. NumPy массив (для научных вычислений)
import numpy as np
np_array = np.array([1, 2, 3, 4, 5])
print(np_array * 2)  # [2, 4, 6, 8, 10]

# 4. Список списков (двумерный массив)
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
```

## **Использовать массив нужно, когда:**
- Нужен быстрый доступ по индексу (O(1))
- Размер известен заранее или редко меняется
- Важна cache locality (последовательный обход)
- Нужна минимальная дополнительная память

### **Избегаем массива, когда:**
- Частые вставки/удаления в начало или середину
- Размер часто и значительно меняется
- Нужна структура, где важен порядок, но не индекс
