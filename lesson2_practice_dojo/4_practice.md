## 1. Транспорт (Bus Route)

### Описание задачи
Необходимо реализовать систему маршрута автобуса, включающую список остановок.
Каждая остановка содержит:
- название
- координаты
- время до следующей остановки

### Обязательная часть
Реализовать следующие функции:
- Добавление остановки
- Расчет общего времени маршрута
- Определение, где будет автобус через N остановок
- Построение обратного маршрута

### Вариативная часть (на выбор)
Реализовать **одну или несколько** функций:

1. Реализовать кольцевой маршрут
2. Найти остановки, до которых автобус доедет за заданное время
3. Добавить расчет времени прибытия (расширение функции "где будет автобус через N остановок")
4. Создать функцию формирования подробного отчета маршрута с сохранением в текстовый файл
5. Вывести маршрут в виде таблицы с выравниванием колонок
6. Сохранить маршрут в текстовый файл, где каждая строка — Base64-кодированная информация об остановке

## 2. Музыкальный плейлист (Playlist)

### Описание задачи
Необходимо реализовать систему управления музыкальным плейлистом.
Каждый трек содержит:
- название
- продолжительность
- жанр
- рейтинг

### Обязательная часть
Реализовать:
- Добавление трека
- Удаление трека
- Перемешивание (shuffle)
- Повтор (repeat one / repeat all)

### Вариативная часть (на выбор)
Реализовать **одну или несколько** функций:

1. Сохранение плейлиста в текстовый файл (Base64, одна строка — один трек)
2. Загрузка плейлиста из Base64-файла
3. Вывод плейлиста в виде таблицы с выравниванием колонок
4. Формирование отчета (общая длительность, средний рейтинг)
5. Фильтрация плейлиста по жанру
6. Поиск N треков в заданном диапазоне времени
7. Формирование списка треков с рейтингом не ниже заданного

## 3. Браузерная история (Browser History)

### Описание задачи
Необходимо реализовать систему хранения истории браузера.
Каждая запись содержит:
- URL
- время посещения
- флаг "закладка"

### Обязательная часть
Реализовать:
- Навигацию "назад / вперед"
- Очистку истории
- Поиск по домену

### Вариативная часть (на выбор)
Реализовать **одну или несколько** функций:

1. Сохранение истории в файл (Base64, одна строка — одна запись)
2. Загрузка истории из Base64-файла
3. Вывод истории в виде таблицы с выравниванием колонок
4. Просмотр истории за заданный период времени
5. Топ-N переходов (наиболее частые переходы между доменами)

## Требования к выполнению
- Использовать линейные структуры данных (динамический массив или LinkedList)
- Обосновать выбор структуры данных
- Обработать граничные случаи (пустые списки, выход за границы и т.д.)
- Код должен быть читаемым и структурированным
- Оформить репозиторий с кодом и выложить на github
