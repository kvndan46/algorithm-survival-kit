# Quiz: Динамический массив vs LinkedList

## Вопрос 1
Ты разрабатываешь приложение для просмотра списка товаров. Пользователь в основном прокручивает список и обращается к элементам по индексу.

**Что выбрать?**
A) Динамический массив
B) LinkedList

## Вопрос 2

**Что выбрать?**
A) Динамический массив
B) LinkedList
