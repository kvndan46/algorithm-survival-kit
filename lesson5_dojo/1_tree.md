## Деревья

**Дерево** - это **иерархическая** структура данных, которая хранит информацию в виде уровней: один элемент является корневым, остальные образуют поддеревья. В отличие от линейных структур данных, например связного списка или стека, дерево не содержит циклов, а связи между элементами называются *ребрами*. Каждый элемент дерева называется **узлом**, и у него могут быть дочерние элементы.

Главная особенность дерева - отсутствие кольцевых связей: из корня можно добраться до любого узла, но нет путей, которые возвращают назад.  Благодаря этому деревья подходят для представления иерархий (файловые системы, структуры организаций, DOM‑деревья в браузерах) и широко применяются в алгоритмах.

---

## Термины и свойства

Чтобы понимать алгоритмы работы с деревьями, важно знать несколько терминов:

- **Узел (Node)** - отдельный элемент дерева. В нём хранятся данные, а также ссылки на потомков.
- **Корень (Root)** - верхний узел дерева, у которого нет родителя. Из корня начинается обход.
- **Родитель (Parent)** - узел, от которого ведёт ребро к другому узлу. Этот другой узел называется **дочерним (Child)**.
- **Лист (Leaf)** - узел, у которого нет детей. Такие узлы находятся на самом нижнем уровне.
- **Внутренний узел** - имеет хотя бы одного потомка.
- **Ребро (Edge)** - связь между узлами. Количество рёбер между корнем и узлом определяет его **глубину**.
- **Уровень (Level)** - номер уровня равен количеству рёбер от корня плюс один. Корень находится на уровне 1.
- **Высота (Height)** - максимальное число рёбер от корня до листа. Зная высоту, можно оценивать время обходов.
- **Поддерево (Subtree)** - часть дерева, включающая некоторый узел и всех его потомков.

Помимо общего определения, часто рассматривают специальные виды деревьев.

**Бинарное дерево** - это дерево, у каждого узла которого не более двух детей: левый и правый.

 **Двоичное дерево поиска** - разновидность бинарного дерева, где для каждого узла левое поддерево содержит только элементы меньше ключа узла, а правое - элементы больше ключа.

## Представление дерева в коде

Одно из простейших представлений - класс узла, содержащий значение и ссылки на потомков. Для бинарного дерева в Python это может выглядеть так:

```python
class TreeNode:
    def __init__(self, value):
        self.value = value      # хранимые данные
        self.left = None        # левый потомок
        self.right = None       # правый потомок


# создаём простое дерево:
#        10
#       /  \
#      5    15
root = TreeNode(10)
root.left = TreeNode(5)
root.right = TreeNode(15)
```

Такой класс можно расширять: добавлять ссылки на родителя, счётчик размера поддерева или использовать список потомков для произвольных деревьев.

Главное - понимать, что у каждого узла хранится значение и набор ссылок на его детей.

## Основные операции

На первом курсе мы ограничимся базовыми действиями:

- **Вставка**. Для двоичного дерева поиска вставка происходит рекурсивно: если новое значение меньше текущего узла, идём в левое поддерево, иначе - в правое. Когда достигаем пустой ссылки, создаём новый узел.
- **Поиск**. Поиск также опирается на порядок в дереве поиска: сравниваем ключ с текущим узлом и спускаемся влево или вправо до совпадения или до того, как дойдём до пустой ссылки.
- **Высота/размер**. Высота вычисляется как 1 + максимум высот поддеревьев. Размер - общее число узлов. Обе функции удобно реализовать рекурсивно.

Простая реализация поиска в дереве поиска на Python:

```python
def insert(root, value):
    """Добавить значение в бинарное дерево поиска."""
    if root is None:
        return TreeNode(value)
    if value < root.value:
        root.left = insert(root.left, value)
    else:
        root.right = insert(root.right, value)
    return root

def search(root, target):
    """Найти значение в дереве поиска."""
    if root is None or root.value == target:
        return root  # None, если не найдено
    if target < root.value:
        return search(root.left, target)
    else:
        return search(root.right, target)
```
