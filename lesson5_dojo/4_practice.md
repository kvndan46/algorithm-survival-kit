## Задача 1 — Бинарное дерево поиска (BST)

### Описание

Реализовать **бинарное дерево поиска** для хранения целых чисел. Каждый узел содержит значение, а также ссылки на левого и правого потомка. Для любого узла все элементы в левом поддереве меньше его значения, а в правом - больше.

---

### Обязательная часть

Реализовать функции:
- `insert(root, value)`: вставить значение в дерево поиска. При необходимости создавать корневой узел.
- `search(root, target)`: найти, содержится ли значение в дереве (возвращать True/False или сам узел).
- `inorder(root)`: вывести значения в порядке возрастания (симметричный обход).

---

### Вариативная часть

1. Реализовать удаление узла `delete(root, value)` с сохранением свойств BST.
2. Написать функции `find_min(root)` и `find_max(root)` для поиска минимального и максимального значения.
3. Подсчитать количество узлов в дереве (`size`).
4. Подсчитать количество листьев (узлов без детей).
5. Вычислить высоту дерева (максимальную глубину).
6. Проверить, сбалансировано ли дерево (разница высот поддеревьев любого узла не превышает 1).
7. Найти k‑й по величине элемент (например, 3‑й минимум).
8. Сформировать отсортированный список всех элементов.
9. Найти сумму значений во всех узлах.
10. Реализовать обход дерева в ширину (BFS) и вывести элементы по уровням.

## Задача 2 - Дерево выражений

### Описание

Дан математический пример в **постфиксной форме** (обратная польская запись.). Необходимо построить **дерево выражения**, где листья — операнды (целые числа), а внутренние узлы — операторы `+`, `−`, `*`, `/`. После построения дерева нужно вычислить значение выражения с помощью рекурсии.

Пример:
1. `2 5 * 3 +` будет представлен в виде дерева
```
        +
       / \
      *   3
     / \
    2   5
```
2. `2 3 + 4 5 * +`

Шаги:
 - 2 3 + -> (2 + 3)
 - 4 5 * -> (4 * 5)
 - потом складываем результаты

```
        +
       / \
      +   *
     / \ / \
    2  3 4  5
```

---

### Обязательная часть

Реализовать функции:
- `build_expression_tree(tokens)`: построить дерево по списку токенов постфиксной записи.
- `evaluate(root)`: рекурсивно вычислить значение выражения, расположенного в дереве.

---

### Вариативная часть

1. Поддержать ввод выражения в инфиксной форме (с круглыми скобками): преобразовать его в постфиксную запись и затем строить дерево.
2. Вывести выражение в виде строки в инфиксной форме с расстановкой скобок.
3. Вывести выражение в префиксной (prefix) форме.
4. Вывести выражение в постфиксной (postfix) форме.
5. Добавить поддержку оператора возведения в степень `^`.
6. Реализовать унарный минус (например, `-a`).
7. Определить высоту дерева выражения.
8. Подсчитать количество операций (внутренних узлов).
9. Допустить переменные и вычислять значение выражения, принимая словарь с их значениями.
10. Упростить выражение, сворачивая константные подвыражения (constant folding).

## Задача 3 - Обход бинарного дерева

### Описание

Дано произвольное бинарное дерево (не обязательно дерево поиска). Требуется реализовать различные методы обхода и вычислить некоторые свойства дерева.

---

### Обязательная часть

Реализовать функции:
- `preorder(root)`, `inorder(root)`, `postorder(root)`: прямой, симметричный и обратный обходы, возвращающие список значений.
- `level_order(root)`: обход в ширину (BFS), выводящий элементы по уровням.
- Создать несколько тестовых деревьев для проверки работы функций.

---

### Вариативная часть

1. Посчитать количество узлов на каждом уровне и вернуть список чисел.
2. Проверить, является ли дерево симметричным относительно своего корня.
3. Найти максимальное и минимальное значения в дереве.
4. Посчитать количество путей от корня до листьев.
5. Вычислить сумму значений по всем путям от корня до листьев.
6. Найти самый длинный путь от корня до листа (возвращать список значений).
7. Вывести «левый вид» дерева (первый узел на каждом уровне).
8. Вывести правый вид» дерева (последний узел на каждом уровне).
9. Определить диаметр дерева (длина самого длинного пути между двумя узлами).
10. Для каждого уровня посчитать сумму значений узлов и вернуть список сумм.
