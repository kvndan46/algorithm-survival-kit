## Рекурсия

При работе с деревьями удобно использовать **рекурсию**. Это техника, при которой функция вызывает сама себя, постепенно упрощая задачу.  Рекурсивный алгоритм делает шаг в сторону решения и затем вызывает себя для решения меньшей подзадачи, пока не достигнет **базового случая** - простого варианта задачи, для которого ответ известен.  Чтобы рекурсия не стала бесконечной, важно определить базовое условие и обеспечить, что каждое рекурсивное вызванное решение приближает нас к этому условию.

В рекурсивных алгоритмах над деревьями базовый случай, как правило, наступает, когда мы сталкиваемся с пустой ссылкой: если узел отсутствует, возвращаемся назад. Именно так работают все обходы деревьев.

---

## Обход в глубину (DFS)

**Depth‑First Search (DFS)** - это способ посетить все узлы дерева, уходя как можно глубже по каждому пути, прежде чем вернуться и перейти к соседним ветвям.  Мы начинаем с корневого узла и рекурсивно обходим потомков. Различают три основных варианта DFS в зависимости от порядка посещения узлов:

- **Preorder (Прямой)**: сначала посещаем текущий узел, затем левое поддерево, затем правое.
- **Inorder (Симметричный)**: сначала обходим левое поддерево, затем посещаем текущий узел, затем правое.
- **Postorder (Обратный)**: сначала обходим левое и правое поддеревья, затем посещаем текущий узел.

В Python обходы реализуются просто - нужно следовать порядку вызовов. Ниже примеры функций для каждого варианта обхода:

```python
def preorder(root, result=None):
    if result is None:
        result = []
    if root:
        result.append(root.value)            # 1. узел
        preorder(root.left, result)         # 2. левое поддерево
        preorder(root.right, result)        # 3. правое поддерево
    return result

def inorder(root, result=None):
    if result is None:
        result = []
    if root:
        inorder(root.left, result)          # 1. левое поддерево
        result.append(root.value)           # 2. узел
        inorder(root.right, result)         # 3. правое поддерево
    return result

def postorder(root, result=None):
    if result is None:
        result = []
    if root:
        postorder(root.left, result)        # 1. левое поддерево
        postorder(root.right, result)       # 2. правое поддерево
        result.append(root.value)           # 3. узел
    return result
```

В каждом случае функция сначала проверяет, что узел существует (базовый случай). Затем совершает действия в соответствующем порядке. Рекурсивные вызовы работают с поддеревьями, постепенно сокращая задачу.

**Сложность**. Любой из этих обходов посещает каждый узел ровно один раз, поэтому время работы - `O(n)`, где `n` — количество узлов. Память также `O(h)`, где `h` — высота дерева, поскольку глубина рекурсивного стека не превышает высоты дерева.

## Обход в ширину (BFS)

**Breadth‑First Search (BFS)**, также известный как **level‑order traversal**, посещает узлы дерева уровень за уровнем: сначала корень, затем всех его детей, затем внуков и так далее. Это означает, что все узлы на одном уровне посещаются раньше, чем узлы на следующем уровне.  В отличие от DFS, BFS не погружается глубоко сразу, а двигается по горизонтали.

Для реализации BFS используется структура **очередь** (Queue). Мы помещаем корневой узел в очередь, затем извлекаем его, записываем значение и добавляем его детей в конец очереди. Так продолжается до тех пор, пока очередь не опустеет.

```python
from collections import deque

def bfs(root):
    result = []
    if root is None:
        return result
    queue = deque([root])
    while queue:
        node = queue.popleft()
        result.append(node.value)
        # добавляем детей в очередь
        if node.left:
            queue.append(node.left)
        if node.right:
            queue.append(node.right)
    return result
```

На каждом шаге мы обрабатываем один узел и помещаем его потомков в очередь. Время работы BFS также `O(n)`, где `n` - число узлов. Память определяется максимально возможным числом узлов на одном уровне; в худшем случае это может быть до `O(n/2)` для полного дерева.

## Выбор между DFS и BFS

* Обходы в глубину полезны, когда нужно полностью исследовать одну ветку, например, при поиске пути к определённому узлу или при вычислении свойств (высоты, размера). Они легко реализуются рекурсивно.
* Обход в ширину удобен, когда нужно обработать узлы по уровням: построить таблицу уровней, найти кратчайший путь в невзвешенных деревьях или найти ближайшего узла, удовлетворяющего условию. Благодаря очереди, BFS реализуется итеративно.

Самая важная мысль из всей теории: `Оба вида обхода посещают все узлы, но порядок обхода различается.`
