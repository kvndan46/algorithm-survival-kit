# Словари и структура Map

## Что такое Map

`Map` — это структура данных, которая хранит пары **ключ -> значение**.
Главная идея в том, что мы обращаемся к данным не по позиции, как в массиве, а по ключу.

Например, если нужно хранить возраст студентов, можно сделать так:

```python
ages = {
    "Anna": 20,
    "Ivan": 22,
    "Maria": 21
}

print(ages["Ivan"])   # 22
```

Здесь "Ivan" — ключ, а 22 — значение.

Такой способ хранения удобен, когда мы хотим быстро получать информацию по имени, id, логину, артикулу товара и любому другому уникальному признаку.

### Чем Map отличается от массива

У массива доступ обычно строится через индекс: arr[0], arr[1], arr[2].
У Map доступ идёт по ключу: map[key].

Это делает структуру очень удобной в задачах, где нужно не просто хранить набор элементов, а связывать один объект с другим.
Например:

	•	имя студента → оценка
	•	id пользователя → профиль
	•	слово → количество его повторений
	•	артикул товара → цена

Вообщем, Map-а отвечает на вопрос:
«Какому значению соответствует этот ключ?»

### Как это связано с HashMap

Во многих языках Map реализуется через хеш-таблицу.
Поэтому часто можно встретить названия HashMap, HashTable, dict, Dictionary.

Смысл у них один: по ключу вычисляется специальное число — хеш, а затем по нему выбирается место, где лежит значение.

Идея выглядит так:

	1.	мы берём ключ
	2.	вычисляем для него хеш
	3.	по хешу находим нужную позицию в таблице
	4.	читаем или изменяем значение

Из-за этого поиск работает очень быстро в среднем случае.

`Хэш-функция` - это алгоритм, который преобразует входные данные (например, строку или файл) в короткое фиксированное значение - хэш.

Ключевые свойства:

	•	Детерминированность - одинаковый ввод всегда даёт одинаковый хэш
	•	Быстрота вычисления
	•	Фиксированная длина результата
	•	Устойчивость к коллизиям - сложно найти разные данные с одинаковым хэшем
	•	Необратимость - по хэшу нельзя восстановить исходные данные

### Почему операции в Map обычно быстрые

Если реализация сделана через хеш-таблицу, то основные операции:

	•	вставка пары key -> value
	•	поиск значения по ключу
	•	удаление по ключу

обычно работают за `O(1)` в среднем случае.

Это не значит, что время всегда одинаковое при любых обстоятельствах.
Если ключи распределяются неудачно и возникает много коллизий, операция может замедлиться.
Но при нормальной хеш-функции и разумном размере таблицы словарь остаётся очень эффективной структурой.

Основные операции

```python
student_scores = {}

student_scores["Anna"] = 95      # вставка
student_scores["Ivan"] = 88

print(student_scores["Anna"])    # поиск по ключу

student_scores["Ivan"] = 90      # обновление значения

del student_scores["Anna"]       # удаление
```

*Обратите внимание*: если ключ уже существует, то новое присваивание не создаёт вторую запись, а перезаписывает значение.

### Алгоритмические сложности

Для словаря на основе хеш-таблицы обычно рассматривают такие оценки:

| Операция                          | Средний случай | Худший случай |
|----------------------------------|----------------|----------------|
| Поиск по ключу                   | O(1)           | O(n)           |
| Вставка                          | O(1)           | O(n)           |
| Удаление                         | O(1)           | O(n)           |
| Проверка существования ключа     | O(1)           | O(n)           |


### Почему в худшем случае появляется O(n)?
Потому что несколько ключей могут попасть в одно и то же место таблицы. Тогда структуре приходится разбирать коллизии, и быстрый доступ превращается почти в линейный поиск.

### Когда используем словари
Словари хорошо подходят в задачах, где нужно быстро находить данные по ключу.

Например:

	•	подсчёт частоты элементов
	•	проверка, встречался ли элемент раньше
	•	хранение соответствий id -> объект
	•	кэширование уже вычисленных результатов
	•	быстрый поиск по справочнику

Один из самых частых примеров:

```python
text = ["cat", "dog", "cat", "bird", "dog", "cat"]

freq = {}

for word in text:
    if word in freq:
        freq[word] += 1
    else:
        freq[word] = 1

print(freq)
# {'cat': 3, 'dog': 2, 'bird': 1}
```

Здесь словарь позволяет за один проход посчитать количество повторений каждого слова.

### Что важно помнить

Словарь очень удобен, но он не заменяет все остальные структуры данных.

Если нужен доступ по индексу и важен порядок позиций, лучше подходит массив или список.
Если нужно быстро находить данные по ключу, чаще всего лучше подходит Map.
