## 1. Сокращатель ссылок

### Описание задачи

Необходимо реализовать упрощённый сервис сокращения ссылок.

Система должна уметь:

- сохранять длинную ссылку
- выдавать ей короткий код
- по короткому коду возвращать исходную ссылку

Например:

- длинная ссылка: `https://example.com/articles/python-basics`
- короткий код: `a1b2`
- результат хранения: `a1b2 -> https://example.com/articles/python-basics`

### Обязательная часть

Реализовать:

- добавление новой ссылки
- получение длинной ссылки по короткому коду
- проверку существования короткого кода
- вывод всех сокращённых ссылок

### Вариативная часть

1. Запретить создание двух одинаковых коротких кодов
2. Если длинная ссылка уже существует, возвращать старый короткий код, а не создавать новый
3. Добавить удаление ссылки по короткому коду
4. Подсчитывать количество переходов по каждой короткой ссылке
5. Выводить самую популярную короткую ссылку
6. Добавить поиск всех ссылок, содержащих заданное слово
7. Выводить все пары в отсортированном виде по короткому коду
8. Ограничить минимальную и максимальную длину короткого кода
9. Добавить возможность изменить длинную ссылку для существующего короткого кода
10. Реализовать обратный поиск: находить короткий код по длинной ссылке

## 2. Электронный журнал группы

### Описание задачи

Необходимо реализовать простой электронный журнал.

Система хранит студентов и их баллы.
Для каждого студента нужно быстро получать текущий результат по имени или по id.

Например:

- `Ivan -> 78`
- `Anna -> 92`
- `Maria -> 85`

### Обязательная часть

Реализовать:

- добавление студента в журнал
- выставление или обновление балла
- получение балла по имени или id
- вывод всех студентов и их результатов

### Вариативная часть

1. Подсчитывать средний балл по всем студентам
2. Находить студента с максимальным баллом
3. Находить студента с минимальным баллом
4. Выводить только тех студентов, чей балл не ниже заданного
5. Подсчитывать количество студентов, не прошедших порог
6. Добавить удаление студента из журнала
7. Проверять, есть ли студент с заданным именем или id
8. Хранить не один балл, а список оценок по нескольким работам
9. Выводить студентов в отсортированном виде по имени
10. Сохранять журнал в файл

## 3. Подсчёт слов в тексте

### Описание задачи

Необходимо реализовать программу, которая анализирует текст и считает, сколько раз встречается каждое слово.

Например, для строки:

`"cat dog cat bird dog cat"`

результат может быть таким:

- `cat -> 3`
- `dog -> 2`
- `bird -> 1`

Это одна из самых классических задач на использование словаря.

### Обязательная часть

Реализовать:

- чтение строки или текста
- разбиение текста на слова
- подсчёт количества повторений каждого слова
- вывод результата в формате `слово -> количество`

### Вариативная часть

1. Игнорировать регистр букв (`Test` и `test` считать одним словом)
2. Убирать знаки препинания перед подсчётом
3. Находить самое частое слово
4. Выводить только слова, которые встретились больше одного раза
5. Подсчитывать количество уникальных слов
6. Выводить результат в отсортированном виде по алфавиту
7. Выводить результат в отсортированном виде по убыванию частоты
8. Исключать из подсчёта служебные слова, например: `и`, `в`, `на`, `the`, `a`
9. Сравнивать два текста и выводить слова, которые встречаются в обоих
10. Сохранять результат анализа в текстовый файл
