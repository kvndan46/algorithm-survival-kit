# А есть еще и ... пространственная сложность алгоритма

Это тоже самое, только не операции и процессор, а про занимаемую память.

Количество дополнительной памяти, используемой алгоритмом, называется **пространственной сложностью**.

Как и временная сложность, пространственная сложность обычно выражается с помощью **нотации Big O**.

---

# Что учитывается в пространственной сложности

При анализе учитывается **дополнительная память**, которую алгоритм использует во время выполнения.

Обычно сюда относятся:

- дополнительные массивы или списки
- структуры данных (например `set`, `dict`)
- память, используемая рекурсией
- временные переменные

При этом память, которая уже передана функции в качестве входных данных, как правило **не учитывается**, поскольку она существует независимо от алгоритма.

---

# Пример: константная пространственная сложность

Рассмотрим функцию поиска максимального элемента.

```python
def find_max(arr):
    max_val = arr[0]

    for x in arr:
        if x > max_val:
            max_val = x

    return max_val
```
