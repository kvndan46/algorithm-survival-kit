# Пример оформления

Реализуйте алгоритм поиск четных чисел.

1. Реализация
```python
def count_even(arr):
    count = 0

    for x in arr:
        if x % 2 == 0:
            count += 1

    return count
```

2. Функция измерения времени
```python
import time

def measure_time(func, data):
    start = time.perf_counter()
    func(data)
    end = time.perf_counter()
    return end - start
```
3. Функция генерации данных
```python
import random

def generate_array(n):
    arr = []
    for i in range(n):
        arr.append(random.randint(0, 10000))
    return arr
```
4. Эксперимент
```python
import time
import random

def count_even(arr):
    count = 0
    for x in arr:
        if x % 2 == 0:
            count += 1
    return count

def generate_array(n):
    arr = []
    for i in range(n):
        arr.append(random.randint(0, 10000))
    return arr

def measure_time(func, data):
    start = time.perf_counter()
    func(data)
    end = time.perf_counter()
    return end - start

if __name__ == '__main__':
    sizes = [100, 1000, 5000, 10000]
    for n in sizes:
        arr = generate_array(n)
        t = measure_time(count_even, arr)
        print(n, t)
```
| n | t,с |
|---|---|
| 100 | 0.00001 |
| 1000 | 0.00008 |
| 5000 | 0.00042 |
| 10000 | 0.00083 |

# Задание для самостоятельной реализации

### 1. Проверка наличия элемента в массиве


Идея алгоритма простая: нужно последовательно пройти по массиву и сравнить каждый элемент с искомым значением.

Если элемент найден — вернуть `True`.

Если массив закончился — вернуть `False`.

### 2. Поиск второго максимального элемента
Алгоритм должен найти второе по величине число в массиве.

Идея алгоритма:

1. хранить два значения — максимальное и второе максимальное (т.е. на первой итерации
`max1 = arr[0]` , `max2 = arr[0]`)
2. пройти по массиву
3. обновлять значения при необходимости

### 3. Бинарный поиск
Бинарный поиск используется для поиска элемента в **отсортированном массиве**.

Алгоритм работает следующим образом:
1. выбирается середина массива
2. если элемент найден — поиск завершён
3. если элемент меньше — поиск продолжается слева
4. если больше — справа

### 4. Построение таблицы умножения
Идея алгоритма:
1. внешний цикл проходит по строкам
2. внутренний цикл проходит по столбцам
3. для каждой пары чисел вычисляется произведение
4.
Например для n = 3:
```
1 2 3
2 4 6
3 6 9
```
