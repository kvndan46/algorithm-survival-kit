## Задача 1 — Система обработки задач (Queue)

### Описание
Реализовать очередь задач.

Каждая задача содержит:
- id (пользователь сам передает идентификатор)
- описание
- приоритет

---

### Обязательная часть

Реализовать:
- enqueue(task)
- dequeue()
- front()
- isEmpty()

---

### Вариативная часть

1. Добавить метод size() — количество задач
2. Добавить метод clear() — очистка очереди
3. Вывести все задачи в очереди
4. Найти задачу по id
5. Удалить задачу по id
6. Подсчитать количество выполненных задач
7. Проверить, есть ли задача с заданным id
8. Добавить нумерацию задач автоматически (идентификатор инкрементируется, а не передается пользователем)
9. Запретить добавление задач с одинаковым id
10. Вывести очередь в виде строки

## Задача 2 — Проверка выражений (Stack)

### Описание
Проверить корректность скобочной последовательности.

Пример:

()[]{} → true
([)] → false

---

### Обязательная часть

Реализовать:
- функцию проверки строки
- поддержку (), [], {}

### Вариативная часть

1. Добавить поддержку `< >`
2. Вернуть позицию первой ошибки
3. Подсчитать количество пар скобок в строке: `([]) -> 2`, `()[]{} -> 3`
4. Проверять только круглые скобки `(` и `)`
5. Проверять строку и игнорировать все символы, кроме скобок `a + (b * c) -> true`,
`if (a[2] > b) -> true`
6. Вывести, каких скобок в строке больше: открывающих, закрывающих, ровно
7. Определить максимальную глубину вложенности скобок
8. Вывести сообщение с причиной ошибки
   Например: «лишняя закрывающая скобка» или «не хватает закрывающей скобки»
9. Показывать содержимое стека после каждого шага
10. Добавить возможность проверять несколько строк подряд:
`["()", "([)]", "{[]}"]` Результат: `() -> true`, `([)] -> false`, `{[]} -> true`
