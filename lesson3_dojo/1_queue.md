# Очередь и стек

## 1. Очередь (Queue)

### Что такое очередь

`Очередь` — это структура данных, в которой элементы обрабатываются в порядке их добавления.
Такой принцип называется **FIFO (First In — First Out)** — «первым пришёл, первым вышел».

Это означает, что первый добавленный элемент всегда будет удалён первым, а новые элементы добавляются только в конец.

Аналогия - это очередь в магазине. Кто встал раньше, тот обслуживается раньше.

---

### Как устроена очередь

У очереди есть два конца.
С одного конца элементы добавляются, с другого — удаляются.

Когда новый элемент приходит, он встаёт в конец очереди.
Когда происходит обработка, берётся элемент из начала.

Таким образом сохраняется порядок.

---

### Основные операции

Добавление элемента в очередь называется `enqueue` или `push`.

Удаление элемента — `dequeue` или `pop`

Также можно посмотреть первый элемент, не удаляя его — это операция `front`.
Для проверки пустоты используется `isEmpty`.

Все эти действия выполняются — за константное время.

---

### Пример

```python
queue = []

queue.append(10)
queue.append(20)
queue.append(30)

print(queue)  # [10, 20, 30]

queue.pop(0)

print(queue)  # [20, 30]
```

### Особенность реализации

При использовании обычного списка удаление первого элемента работает медленно, потому что остальные элементы сдвигаются. Поэтому на практике используют оптимизированные структуры, например в python в стандартной коллекции есть - `deque`.

```python
from collections import deque

queue = deque()

queue.append(1)
queue.append(2)

queue.popleft()
```

### Где используется очередь

Очередь применяется в ситуациях, где важен порядок обработки.
Например, при обработке запросов, в очередях задач, а также в алгоритмах, таких как обход графа в ширину.

## Стек (Stack)

`Стек` — это структура данных, работающая по принципу **LIFO (Last In — First Out)** —
«последним пришёл, первым вышел».

Это означает, что последний добавленный элемент будет удалён первым.

Пример - это стопка тарелок: мы кладём сверху и берём тоже сверху.

### Как устроен стек

Все операции происходят с вершиной стека:
1. новые элементы добавляются сверху
2. удаляются тоже сверху

Таким образом, доступ есть только к последнему элементу.

### Основные операции

Добавление элемента называется `push`.
Удаление — `pop`.

Можно посмотреть верхний элемент без удаления с помощью `peek`.
Проверка пустоты выполняется через `isEmpty`.

Все операции также выполняются за постоянное время.

Пример
```python
stack = []

stack.append(10)
stack.append(20)
stack.append(30)

print(stack)  # [10, 20, 30]

stack.pop()

print(stack)  # [10, 20]
```
